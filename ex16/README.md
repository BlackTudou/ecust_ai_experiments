# 实验16：工业故障诊断 - 基于CNN和LSTM的轴承故障诊断

## 实验目的

使用深度学习模型（CNN和LSTM）对轴承故障进行诊断，实现高效、准确的故障识别，替代传统依赖人工经验或手动特征提取的方法。

## 实验原理

1. **工业故障诊断需求**：传统故障诊断依赖人工经验或手动特征提取，效率低且泛化能力差；深度学习通过自动提取数据中的故障特征，可实现高效、准确的故障识别。

2. **深度学习故障诊断原理**：
   - **CNN用于故障诊断**：将时间序列数据转换为"频谱图"（如通过短时傅里叶变换STFT将振动信号转换为二维频谱图），利用CNN的局部特征提取能力，从频谱图中识别故障特征。
   - **LSTM用于故障诊断**：直接处理时间序列数据，利用LSTM的长短期记忆能力，捕捉故障发展过程中的时序依赖关系（如故障从萌芽到恶化的信号变化）。

3. **诊断性能评估指标**：准确率（Accuracy）、故障类别召回率（Recall）、精确率（Precision）、F1值。对于不平衡故障数据（正常样本多、故障样本少），需重点关注故障类别的召回率（避免漏诊）。

## 实验步骤

1. **故障数据准备与预处理**：
   - 数据来源：模拟CWRU轴承故障数据集（包含正常、内圈故障、外圈故障、滚动体故障的振动数据，采样频率12kHz）
   - 数据预处理：
     - 数据清洗：小波阈值去噪处理（db4小波基）
     - 数据转换（CNN用）：对振动时间序列数据进行短时傅里叶变换（STFT），生成二维频谱图（64×64），作为CNN的输入
     - 数据重塑（LSTM用）：将时间序列数据重塑为LSTM输入格式（样本数 × 4 × 4，每组样本长度1024，按256为时间步长，分为4个时间步，特征数为4）
     - 数据划分与标签：将数据按7:2:1划分为训练集、验证集、测试集，为不同故障状态分配标签（正常=0，内圈故障=1，外圈故障=2，滚动体故障=3）

2. **基于CNN的故障诊断模型构建与训练**：
   - 模型结构设计：输入层（64×64×1的频谱图）→卷积层1（32个3×3卷积核，ReLU激活）→池化层1（2×2最大池化）→卷积层2（64个3×3卷积核，ReLU激活）→池化层2（2×2最大池化）→扁平化层→全连接层1（128神经元，ReLU激活）→Dropout层（0.5）→输出层（4个神经元，Softmax激活，对应4种故障类别）
   - 模型训练：优化器选择Adam（学习率0.001），损失函数选择CrossEntropyLoss（多分类），评估指标选择准确率、召回率、F1值，训练epochs=30，batch_size=32，使用验证集监控过拟合

3. **基于LSTM的故障诊断模型构建与训练**：
   - 模型结构设计：输入层（4×4的时间序列数据）→LSTM层1（64个神经元，ReLU激活，return_sequences=True）→LSTM层2（32个神经元，ReLU激活）→全连接层（64个神经元，ReLU激活）→Dropout层（0.5）→输出层（4个神经元，Softmax激活）
   - 模型训练：与CNN模型设置相同的优化器、损失函数、评估指标、epochs和batch_size，对比两种模型的训练收敛速度

4. **故障诊断模型评估**：
   - 基础性能评估：在测试集上分别运行CNN和LSTM模型，计算整体准确率、各类别（正常、内圈故障、外圈故障、滚动体故障）的精确率、召回率和F1值，生成分类报告
   - 混淆矩阵分析：绘制两种模型的混淆矩阵热力图，直观观察模型在各类故障上的诊断效果

## 数据说明

本实验使用模拟的CWRU轴承故障数据，包含以下4种故障类别：
- **正常** (类别0)：正常运行的轴承振动信号
- **内圈故障** (类别1)：内圈故障的振动信号，特征频率为转频的5.4倍
- **外圈故障** (类别2)：外圈故障的振动信号，特征频率为转频的3.6倍
- **滚动体故障** (类别3)：滚动体故障的振动信号，特征频率为转频的4.7倍

每个类别生成500个样本，每个样本长度为1024个数据点，采样频率为12kHz。

## 模型结构

### CNN模型

```
输入层 (1, 64, 64)
  ↓
卷积层1 (32个3×3卷积核) + ReLU + 2×2最大池化
  ↓
卷积层2 (64个3×3卷积核) + ReLU + 2×2最大池化
  ↓
扁平化层
  ↓
全连接层1 (128神经元) + ReLU + Dropout(0.5)
  ↓
输出层 (4神经元) + Softmax
```

### LSTM模型

```
输入层 (4, 4)
  ↓
LSTM层1 (64神经元) + ReLU (return_sequences=True)
  ↓
LSTM层2 (32神经元) + ReLU
  ↓
全连接层 (64神经元) + ReLU + Dropout(0.5)
  ↓
输出层 (4神经元) + Softmax
```

## 评估指标

- **准确率 (Accuracy)**: 正确分类的样本数占总样本数的比例
- **精确率 (Precision)**: 预测为正类的样本中，实际为正类的比例
- **召回率 (Recall)**: 实际为正类的样本中，被正确预测为正类的比例
- **F1值**: 精确率和召回率的调和平均数

对于不平衡故障数据，重点关注故障类别的召回率，避免漏诊。

## 实验总结

### CNN与LSTM在故障诊断中的适用场景

- **CNN擅长处理频谱图的空间特征**：通过卷积操作从二维频谱图中提取局部特征，能够识别故障在频域中的空间模式
- **LSTM擅长捕捉时间序列的时序特征**：通过长短期记忆机制学习故障发展过程中的时序依赖关系，能够捕捉故障从萌芽到恶化的信号变化

### 深度学习在工业故障诊断中的关键技术要点

1. **数据预处理**：
   - 小波去噪：去除传感器异常导致的噪声
   - STFT转换：将时间序列转换为频谱图（CNN用）
   - 时间序列重塑：将数据重塑为LSTM输入格式

2. **模型结构设计**：
   - CNN用于空间特征提取（频谱图）
   - LSTM用于时序特征提取（时间序列）

3. **泛化性提升**：
   - Dropout正则化：防止过拟合
   - 数据增强：提高模型泛化能力
   - 早停法：监控验证集性能

4. **评估指标**：
   - 准确率、精确率、召回率、F1值
   - 重点关注故障类别召回率（避免漏诊）

### 实际工业应用中的改进方向

1. **小样本故障诊断**：
   - 使用迁移学习：利用预训练模型
   - 数据增强：生成更多训练样本
   - 少样本学习：Few-shot learning方法

2. **实时诊断优化**：
   - 模型压缩：减少模型参数量
   - 边缘计算：在设备端进行推理
   - 在线学习：持续更新模型

3. **多传感器融合**：
   - 结合振动、温度、声音等多种传感器数据
   - 多模态深度学习模型

4. **可解释性提升**：
   - 使用注意力机制：突出重要特征
   - 特征可视化：理解模型决策过程

## 注意事项

1. 本实验使用模拟数据，实际应用中应使用真实的CWRU数据集或实验台采集的数据
2. 如果使用真实的CWRU数据集，需要下载数据并修改数据加载函数
3. 模型性能可能因数据质量、模型参数等因素而有所不同
4. 建议根据实际应用场景调整模型结构和超参数
